## Projects

### Sidekick

Asynchronous software development agent
Repository: https://github.com/sidedotdev/sidekick

Overview:

• Designed for professional software engineers with large existing codebases
• Comparable to commercial agentic dev tools, despite being a solo side project
• Being used by coworkers at Remitly alongside other agentic AI tools

Development Process:

• Started building the agent when LLMs weren't capable enough (GPT-3.5 era),
  allowing it to quickly leverage smarter models as they became available
• Dogfooded to build itself, producing a valuable stream of continuous feedback
  in a complex, growing codebase (reaching 70K lines of Go, TypeScript, and Vue)
• Continuously refined based on literature review and ideas from failure modes
  observed or opportunities identified while dogfooding
• Gathered feedback from coworkers at Remitly performing real-world tasks across
  a diverse set of codebases

Noteworthy Features:

• Human-in-the-loop system with Kanban UI for managing parallel async
  agents, enabling engineers to manage multiple workstreams easily
• Built-in planning and requirements analysis with approval gates, to improve
  adherence to developer intent
• Sophisticated retrieval system, based on embeddings of code signatures for
  token-efficient code context localization prior to further agentic tool calls
• Hierarchical verification system for high-quality environmental feedback, with
  a strong emphasis on testing, improving the quality of final artifacts and
  reducing the end-to-end developer effort required to complete tasks
• Code hallucination detection based on fuzzy match to provided context
• LSP integration for auto-fixing and retrieval of references
• Client/server architecture for flexibility in deployment and UX surfaces
